# Neko Aurora: production UX/UI audit (2026-10-24)

Scope: the whole user lifecycle on a 390 px phone (light and dark), local hosted build plus the Railway test deployment.
Tools: `app/tests/aurora/lifecycle-shots.mjs` (screenshot tour), `a11y.mjs` (names, 44 px targets, contrast, reduced motion), `anim-rec.mjs` (screen recording of a working turn).
Evidence: `/workspace/neko-bot-shots/aurora/audit-2026-10-24/`.

Status: **fixed** = changed and verified; **ok** = checked, nothing to change; **open** = known and not fixed (reason given).

| # | Area | Finding | Status |
|---|---|---|---|
| 1 | Working status | A spinner, not the bot; the line restarted its animation on every re-render; it flashed after the reply landed; text written just before a tool call flickered | **fixed**: the bot's own mascot moves per phase (bob, scan, hop, sway, wiggle; eyes blink), shine-sweep text, crossfade between phases, one persistent node, a 2 s landing grace, drafts shown only after 450 ms |
| 2 | Phase wording | Generic text only | **fixed**: the wording follows the tool (web, page, command, file, slides, video, spreadsheet, document, image, MCP, bot, memory, waiting for approval); "Đang suy nghĩ" moves on to "Đang sắp xếp ý" and "Đang hoàn thiện câu trả lời" |
| 3 | Composer | Turned into a stop button while the bot worked | **fixed**: never locks; voice when empty, send when there is text; stop sits on the status line |
| 4 | Sending | Quick messages were merged into one bubble | **fixed**: each is its own bubble at once, stacked |
| 5 | Streaming | Chunks; a lone "Đ" bubble | **fixed**: word-by-word reveal (catches up when behind); a draft needs a whole first word |
| 6 | Motion | No entry motion; cards popped in | **fixed**: rise/fade for new messages only (not on re-render), card entry, folds animate open, press states; transform/opacity only; `prefers-reduced-motion` stops all of it (a11y.mjs: 0 animated under reduce) |
| 7 | Scrolling | Always forced to the bottom | **fixed**: follows new text until the user scrolls up, re-arms on scroll back or send, re-anchors on keyboard (visualViewport) |
| 8 | Sign-in | "Deploy on Railway" was a full-weight black button competing with sign-in | **fixed**: secondary outline button |
| 9 | Sign-in errors | Invalid email and wrong code messages | **ok** ("Email không hợp lệ", "Mã không đúng hoặc đã hết hạn") |
| 10 | Onboarding | One-button setup, goal cards, free quota line | **ok** |
| 11 | Empty thread | A new bot or group opened to a blank screen | **fixed**: the bot's mascot, name, description and three starter chips; groups show stacked member mascots, "Nhóm gồm … và …" and group starters |
| 12 | Dark mode | Sign-in followed the device but the app stayed light | **fixed**: new default "Theo thiết bị" follows the device and switches live; explicit Sáng/Tối/… still win |
| 13 | Dark contrast | Near-black mascots (#2a2320) vanished on black | **fixed**: lifted to #7a6c63 on dark themes (≥3:1 graphic contrast, eyes still white) |
| 14 | Settings header | Showed the server host ("127.0.0.1:18791") | **fixed**: name, email, plan and today's quota |
| 15 | PWA install | No way to install from the app | **fixed**: "Cài app lên màn hình chính" (Android prompt; iOS Share-menu hint); hidden in the app shell or when installed. Manifest gets id, lang and a light splash/theme colour matching the app |
| 16 | Notifications | Toggle, per-bot mute, push via VAPID | **ok** |
| 17 | Offline/reconnect | Banner "Ngoại tuyến · tin nhắn sẽ chờ được gửi"; the outbox resends with nonces | **ok** |
| 18 | Accessibility | Names, 44 px targets, WCAG AA text contrast (light and dark) | **ok** (a11y.mjs ISSUES 0 in both themes); status line has role=status + aria-live; stop button labelled "Dừng" |
| 19 | First load | Static files were sent uncompressed with no validator (app.js 113 KB on every load) | **fixed**: gzip (app.js 39 KB) + ETag/304 revalidation (unit test) |
| 20 | Long chats | Each server event re-renders the visible thread (max 200 messages) | **open**: fine at 200; virtualising is a larger change. Streaming does not re-render (draft-only paint) |
| 21 | Usage, memory, search | Range tabs, per-bot/per-kind totals; memory add/ask/dedupe; empty search says so | **ok** |
| 22 | Group chat | A "both of you" prompt got an answer from one member only | **open**: routing picks the best member; a "everyone answer" rule needs a server change |
| 23 | iOS safe areas | viewport-fit=cover and safe-area insets in place | **ok** (headless can't show a notch; checked in CSS) |
| 24 | iOS keyboard / Dynamic Type | Re-anchor added; Dynamic Type exists for chat text in the iOS shell | **open**: needs a real device; not testable in headless Chrome |
| 25 | Vietnamese copy | Reviewed every screen in the tour | **ok**; new strings are natural Vietnamese |
| 26 | Mid-turn messages | Must be taken in while the bot works | **ok**: injected before the next model call or tool step, the stream interrupted and rebuilt (inbox tests); live: 3 follow-ups folded into one answer |
