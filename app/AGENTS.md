# Neko Bot working rules

- Keep existing files, archives and other repositories intact.
- Implement the 2026-10-11 direction: Tauri UI, Rust trusted host, Go control plane; Neko Core owns the agent loop.
- Grok bundles are read-only UX references. Do not execute or copy unlicensed code/assets.
- Do not deploy, call a paid provider, transmit secrets, create grants or push without the user's separate authorization.
- Scan candidate files for secrets before every local Git checkpoint. Never print matched values.
- Scope changes honestly: local journal tests are not cloud sync, fixture tests are not model evaluation, narrow browser checks are not phone acceptance.
- Record the exact code commit, command, environment and pass/fail/blocked for validation.
