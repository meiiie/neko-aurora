# Local surface bridge v1

The Go journal owns durable Neko Aurora adapter sessions. This slice uses the existing authenticated local-owner transport. It adds no CORS exception, cookie bootstrap, OS app attestation, external connector, provider grant or cloud route. Wiii supplies a trusted same-origin request transport; the adapter cannot borrow Core task/session authority from a source UI ID.

`local_surface_bridge_v1` advertises `POST /v1/adapters/sessions` with `{sourceApp,sourceSessionId,sourceThreadId,channelId,expectedChannelRevision,clientNonce}`. Source app is `wiii` or `core-tui`; source references are bounded opaque ASCII identifiers. The server derives adapter ID, local owner/space and the relative `returnRoute`. Current exact channel revision is required. Same-nonce retries return the original record; changed origin or scope rejects.

`POST /v1/adapters/sessions/{id}/messages` accepts `{botId,text,lane,clientNonce,sourceMessageId,accountId?,accountRevision?,projectId?,projectRevision?,fileIds?}`. Source message identity is unique in that adapter. The original nonce is preserved in `work.adapterPin`; the work nonce is a server-derived namespace digest. `work.text` remains the original text even when an initial `@bot` changes the recipient. `sourceBotId` identifies the sender bot when routing changes. ACK shape is `{work,duplicate}` and carries immutable `adapterPin` keys `adapterSessionId`, `sourceApp`, `sourceSessionId`, `sourceThreadId`, `sourceMessageId`, original `clientNonce`, `channelRevision`, and `returnRoute`. Unknown owner, channel, Core authority or arbitrary reply-route fields reject.

`GET {returnRoute}?after={cursor}` returns the bound adapter/source/channel/owner scope and cumulative assistant updates. Each update has stable `replyId`, `requestId`, original `sourceMessageId`, recipient `botId`, `role`, cumulative `text`, status, journal sequence and optional artifact receipts. A page scans at most 200 journal events and at most 900,000 JSON bytes, coalescing each stable reply to its newest cumulative update and advancing cursor only to the last included event, including unrelated events; consumers upsert by stable reply ID and retain only the greatest sequence. Cursor ahead of the journal rejects. No other adapter's work, private history or another channel's events enter the page. Current source revocation suppresses historical source-derived text/files even when replay starts at zero. A channel revision change returns 409 and requires an explicit newly scoped session; it never silently rebinds old pending requests.

The session and reply receipt survive local service restarts. Lost ACK retries return the original fenced request even after channel or source access changes. Wiii may safely persist an outbox of original source identity, nonce and frozen selections; transient transport failures retry those same bytes, while permanent rejections require explicit repair or discard. A source label is local owner provenance, not proof that another installed application was authenticated. Full IDE transport/bootstrap, Core TUI renderer integration, cross-device sync and external channel connectors retain separate acceptance gates.
