Current App runtime/UI code is a656edc2c7cdb05d4fd1eea81eaecc5db4efffd9. The Rust host passes its descriptor after clearing inherited environment. Missing, modified or partial descriptors fail closed.

The Windows helper holds an exclusive file handle and a retained parent-process handle, binding PID, full creation FILETIME and Core digest. A completed session retains a `released` marker. A v2 `held` marker can be reclaimed only after the exact owner is proved dead. Empty, malformed, unknown, live and v1 markers are refused without rewriting their bytes. The old pinned Core digest is retained for journal replay; automatic v1 stale-lock migration is unavailable.

Normal resume rotates activation by one. If pinned Core already persisted the next activation before App recorded admission, its exact `prior_receipt_retry` receipt permits a bounded step of two. Task, root, session, Core digest and execution authority must match. Both admission and replay require the verified staged attempt binding; arbitrary jumps and unbound recovery flags are denied. Pending or unknown host effects must be reconciled before admission.
