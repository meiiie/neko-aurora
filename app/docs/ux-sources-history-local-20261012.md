# Local source metadata and public history export

The approved light layout remains unchanged. “Nguồn đã dùng” opens a read-only task dialog containing source kind, reason, pinned/current revision and usability. It never displays or stores source text, excerpts, bot instructions, raw context, credentials or runtime receipts. A current file name is shown only while usable. Scope changes and relevant revocations discard the displayed metadata; late GET responses cannot move navigation or overwrite a draft. A collaboration with no stages has no fabricated source task.

“Xuất lịch sử nhóm/dự án” uses a local authenticated attachment link bound to the current shared channel and selected project. A stale project disables the links rather than broadening to the whole channel. Private conversations retain their existing export. The export includes public owner requests, one goal per collaboration, the final response and authorized artifact metadata. It is not a file backup, raw context export, private bot history or permission grant.

The owned runner is `scripts/ui_sources_history_local.mjs`. Working-source evidence is in `E:/CodexScratch/local-daily-use-20261012/ui-worker/l03-l04-actual-r2/results.json`; all checks passed, with actual compiled Go GETs, genuine Chrome JSON/text attachment downloads and no service sequence mutation. The prior r1 failed because its harness used the private filename prefix; the shared endpoint correctly uses the fixed `neko-public-<channelID>` prefix. Both rounds are retained. VM negatives and sanitized metadata/revocation cases are recorded separately.

Desktop, mobile and short-height screenshots were inspected. These are local queued API/browser fixtures, not Core source selection quality, native Tauri, a physical phone, assistive-technology speech, real providers or cloud acceptance. Source/binary hashes and the working-tree flag are in each receipt. A clean combined checkpoint and regression rerun remain the integrator's final gate.
