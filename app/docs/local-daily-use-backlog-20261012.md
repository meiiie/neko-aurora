## Ranh giới và authority

Core vẫn sở hữu loop, logical session/task, memory và compaction. Go chỉ control-plane/authority/source projection/durability, UI chỉ presentation. Root giữ integration/Git; UI và independent review được phân công ownership riêng khi cần. Không sửa Core/Wiii contracts tùy tiện để làm một test xanh. Khi một phần cần Core contract mới, ghi dependency và tiếp tục phần độc lập khác trong bảng.

Cloud auth/pairing/transport/database/object store/installable phone, verified external recipients/connectors, real provider/broker/OAuth/model evaluation, portable recovery key/active restore, semantic memory/compaction và destructive retention vẫn là missing code/design hoặc explicit deferred actions trong full matrix.
