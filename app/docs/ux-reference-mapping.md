# Neko UX reconstruction from the local Grok reference

The previous beige editorial interface is **rejected**. Its smoke tests verified narrow behavior, not visual acceptance. This revision reads the supplied 0.68.1 renderer assets as static reference material; it does not execute that bundle or reproduce its branding, proprietary code, icon fonts or downloaded fonts. Neko uses authored HTML/CSS/JS, a new cat mark and the installed Windows system font.

Neko mint is an original accent. System-font metrics and contrast, actual pixels, native dialog interaction, list stability and screenshots must be measured after building. Acceptance is split: functional fixture checks, measured layout/accessibility, reviewed native screenshots, and real phone/cloud/provider gates. Passing the first two does not declare the latter accepted. The redesign remains under inspection until its actual rendered screens have been reviewed.
