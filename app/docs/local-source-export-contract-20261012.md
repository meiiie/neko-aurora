# Read-only sources and public history

Capability `local_source_explanation_v1`: `GET /v1/tasks/{requestId}/sources?channelId=...&projectId=...` returns `{version:1,requestId,channelId,projectId?,atSequence,usable,omitted,sources}`. projectId is required exactly when the task is project-bound. Duplicate/unknown query keys are refused. The local authenticated owner, task publication audience and current project-channel binding must match. A source permission change is reported as unusable metadata; no regrant or execution is triggered.

Source items contain `id,kind,reason,pinnedRevision,currentRevision,usable` and optionally an authorized file name. Kinds are primary/history/profile/project/file/continuity/plugin. Reasons describe the literal existing selector: owner request, bounded completed turns in the same scope, explicit file selection or bounded filename/text match, intake profile/project metadata, and selected schema pins. Revoked file names are omitted. Request/reply text, source excerpts, profile instructions, continuity decisions, raw context, credential, leases and runtime payloads are absent. This explains selection metadata and current access, not semantic model quality.

Capability `local_public_history_export_v1`: `GET /v1/channels/{channelId}/export?format=json|text&projectId=...` downloads current shared-channel public history, optionally filtered to exactly one current channel-bound project. Private conversations retain their existing separate export route. Shared export includes regular public owner messages/replies and one owner goal per finite group; generated stage instructions and intermediate stage rows are omitted, while the completed final public reply can appear. Authorized final artifact metadata uses existing channel-scoped download paths; file bytes are not bundled. Context/credential/account/runtime metadata is never copied into the export.

Current audience revision and project membership fence inclusion. File links require current source access. Export is bounded by existing historyexport limits (500 rows, 1MiB encoded output, 64KiB per message text/reply); malformed/oversized or recognized sensitive output fails closed. Neither endpoint mutates the journal. JSON and UTF-8 text downloads are local artifacts, without public hosting or remote sync.
